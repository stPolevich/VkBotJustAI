<h1 align="center">VK Bot на Spring Boot</h1>


<h2>Описание проекта</h2>
Этот бот для ВКонтакте отвечает пользователям, цитируя их сообщения. При получении любого текстового сообщения, бот отправляет ответ в формате: "Вы сказали: [текст сообщения]".  

Пример работы:

<img src="https://github.com/stPolevich/VkBotJustAI/blob/main/docs/images/screenBot.png"/>

<h2>Особенности реализации</h2>

* Написан на Java с использованием Spring Boot

* Реализует API ВКонтакте для ботов без использования сторонних библиотек

* Готов к развертыванию на сервере или локально с использованием ngrok

<h2>Требования</h2>

* Java 17 или новее

* Maven 3.6+

* Учетная запись ВКонтакте с правами на управление сообществом

* (Опционально) Ngrok для локального тестирования

<h2>Установка и настройка</h2>

<h4>1. Настройка сообщества ВКонтакте</h4>

* Создайте новое сообщество или используйте существующее

* Перейдите в "Управление" → "Работа с API"

* Включите "Long Poll API" и "Возможности ботов"

* Создайте ключ доступа с необходимыми правами

* Запишите:

  * ID сообщества

  * Ключ доступа

  * Секретный ключ (если используется подтверждение сервера)

  * Код подтверждения сервера

<h4>2. Настройка приложения</h4>

* Клонируйте репозиторий

* Настройте параметры в application.yml:
```javascript
server:
  port: 8080

vk:
  access-token: "your_vk_access_token_here"
  group-id: your_group_id_here
  confirmation-code: "your_confirmation_code_here"
  secret-key: "your_secret_key_here"
```
* Соберите проект

<h4>3. Запуск</h4>

* Запустите приложение

* Для локального тестирования используйте ngrok:

```javascript
ngrok http 8080
```

И укажите полученный URL в настройках Callback API ВКонтакте.

<h2>Использование</h2>

После настройки просто отправьте любое текстовое сообщение боту в личные сообщения сообщества. Бот ответит, цитируя ваше сообщение.

```
Пользователь: Привет, как дела?
Бот: Вы сказали: Привет, как дела?
```
